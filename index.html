Use Chrome or Edge on desktop with Web Serial support. USB access is blocked in this context. Open this site over HTTPS.

Use a data-capable USB cable. Disconnect other serial monitors before installation. Flashing replaces the firmware currently on the device.

Installation

  1. Connect the device to your computer using USB.
  2. Select the hardware and firmware version.
  3. Press install and choose the serial port.
  4. Wait until the process finishes before disconnecting.
